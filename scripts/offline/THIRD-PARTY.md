# Bundled language servers

This distribution includes Eclipse JDT Language Server 1.62.0, downloaded from
the [Eclipse milestone repository](https://download.eclipse.org/jdtls/milestones/1.62.0/).
The upstream project is licensed under EPL-2.0. Its upstream `LICENSE` file is
included next to this notice in the distribution.

Archive: `jdt-language-server-1.62.0-202610131109.tar.gz`

SHA-256: `f587dafd8410633c2c2bf005e853a2bbb03cddee88933d49bfe6d9cb1cf09342`

This distribution also includes
[TypeScript Language Server 6.0.2](https://www.npmjs.com/package/typescript-language-server)
and [TypeScript 6.0.3](https://www.npmjs.com/package/typescript), obtained from
the official npm registry. Both packages are licensed under Apache-2.0; their
upstream license files are retained under `typescript-lsp/node_modules/`.

No Java or Node.js runtime is included. Provide Java 21 or newer and Node.js
22.22.2 or newer on the deployment host.
