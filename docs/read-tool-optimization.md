# `read` 工具的有界读取

当前应用在 Solon AI 4.1.1 的 `read` 之上注册同名 Talent。仅当 AgentFactory 原本授予代理 `read` 时才注册；工具激活时它排在内置 TerminalTalentProxy 后面，因此覆盖内置实现，不增加代理权限。

本地文件（包括本地逻辑挂载）默认尝试读取 4000 行，`limit` 最多 8000 行；编号正文最多 256 KiB，单行最多展示 64 Ki 字符。达到行数或字节上限时返回下一页 `offset`。超长单行会扫描到下一行，但不缓存整行；输出明确说明该行后半段未返回。扫描使用固定大小的缓冲区，因此内存占用不随文件或单行长度增长。读取完仍触发原有 LSP 预热钩子。对于不超过 16 MiB 的本地文件，结果还附带 SHA-256 文件版本，供 `edit/write` 作为修改前提。

路径仍经 Solon 内部的 `TerminalSupport.resolveSafePath` 校验，保留工作区、符号链接、挂载点、物化缓存和敏感路径限制。实现使用反射取得同一 `TerminalSupport` 实例；若上游结构改变，会在构建工具时失败，而不会绕开校验。升级 Solon AI 时应优先将有界读取及安全路径解析能力合并到上游公开 API，移除这层兼容实现。

非本地虚拟挂载仍委托 Solon 原始 `read`，保留其权限判断和 10 MiB 来源上限；它尚未使用本地文件的 256 KiB/单行截断策略。

同一会话再次读取同一路径与范围时，工具先计算当前文件 SHA-256。若与上次一致且上次读取快照仍在当前会话的归档目录，返回简短的 `<read-unchanged>` 引用、文件版本和可恢复的 `@tool-results/<id>.txt` 路径，不再重新扫描行正文或向模型重发正文。第一次读取在成功后保存快照；保存失败则保留原文且不建立短引用。快照索引最多 512 项，不跨会话共享。大于 16 MiB 的文件不使用这一优化；后置的可见内容投影仍由 `ToolResultContextInterceptor` 负责。

文件身份按路径守卫校验后的真实路径判断，`file.txt`、`./file.txt` 和指向同一文件的本地逻辑路径可复用；范围按默认值及上限归一化后比较。空文件同样支持引用，越界等读取错误不会成为引用来源。即使只请求部分行，版本仍基于整个文件内容计算：文件其他位置变化也会返回新的读取正文。快照丢失时重新读取并建立新的可恢复快照，再次读取才恢复短引用；短引用始终保留原分页的续读提示。

成功读取的 SHA-256 同时由后端按会话记录，供 `edit/write` 自动校验，模型不需要抄写或传入摘要。历史快照读取不会替当前文件刷新修改基线；收到本次工作区 read 的结果后，应在下一轮工具调用中发起修改。
