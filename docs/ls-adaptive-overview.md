# `ls` 自适应浅层概览

默认 `ls(path=".")` 在 `recursive=false` 时使用 `mode=auto`。结果先按目录优先、名称排序列出当前层，避免某个大目录的文件占满首页而掩盖其他兄弟目录。当前层最多返回 200 项（可用 `limit` 调整，硬上限 500），`after` 游标格式为 `0:<目录名>` 或 `1:<文件名>`，应原样用于同模式续页。

模型看到的是 `├──` / `└──` 树形文本：当前层目录与文件在根下，小子树直接缩进显示，收起或深度边界标记写在对应目录节点上。`limit` 只计算当前层条目；系统先为本页所有当前层节点预留输出空间，再用剩余预算展开小子树，因此展开不会遮住后续兄弟目录。

对本页每个直属目录，工具最多继续探查两层（即相对本次 `path` 的第三级），最多记 13 个可见条目：不超过 12 项就列出浅层条目；超过则显示“至少 13 项”和至多 3 个样例，不声称知道整个子树的精确数量。若三级边界仍有目录，会明确标注更深层未扫描。根目录及子树沿用 Solon 路径守卫、忽略与隐藏规则；探查失败会标记不完整，不把失败当作空目录。

`ls(mode="flat")` 只列当前层；`ls(recursive=true)` 递归全部层级，返回量仍受单页条数和字符预算限制。
可选 `max_depth`（1～64，仅递归模式可用）显式限制深度：目标目录是第 0 层，其直属项是第 1 层。
达到深度边界的目录会标注未展开，页尾不会把受限结果宣称为完整递归。
`after` 仅用于续接相同 path/recursive/max_depth 范围内的条目，不能继续深入被深度限制的子树；
需要查看更深内容时，移除/增大 max_depth 或对边界目录单独调用 ls。
自适应模式的游标不与 flat/recursive 混用。已知道目标文件名或扩展名时，优先用 `glob` 跨目录定位；
递归分页仍需扫描符合条件的目录树以保证全局字典序，超大目录宜缩小 path 或显式限制深度。
扫描被取消或路径读取失败时明确标记结果不完整；不跟随目录符号链接，继续应用既有隐藏、忽略及沙箱规则。
