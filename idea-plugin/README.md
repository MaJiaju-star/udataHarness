# UData Harness IDEA plugin

IDEA 插件与网页共用 Solon Web 后端。首版支持本机 HTTP 服务，要求后端可以访问当前项目目录。
插件不启动或停止后端，关闭 IDEA 不会影响网页中使用的服务。

## 安装和使用

1. 在仓库根目录构建并启动服务：

   ```powershell
   npm.cmd --prefix frontend run build
   mvn package -DskipTests
   java -jar target/udata-harness.jar
   ```

   模型配置沿用项目 README；不要在插件中配置或保存模型 API 密钥。

2. 用 JDK 21 构建插件：

   ```powershell
   cd idea-plugin
   .\gradlew.bat buildPlugin verifyPluginStructure
   ```

   安装包位于 `build/distributions/udata-harness-idea-0.1.6.zip`。
   使用 IDEA **Settings → Plugins → 齿轮 → Install Plugin from Disk** 安装 ZIP 并按提示重启。
   编译基线为 IDEA Community 2024.3.6，最低平台构建号为 243。IDE 必须使用支持 JCEF 的运行时。
   调试可运行 `.\gradlew.bat runIde`，在开发实例中打开本地项目。

3. 打开右侧 **UData Harness** 工具窗口，输入 `http://127.0.0.1:8080` 及与网页相同的 `userId`。
   点击“测试连接并打开项目”。插件检查 `/api/health`，注册项目工作区，然后加载插件模式页面。
   设置保存在项目的 IDEA 配置中，下一次打开自动连接。

4. 新建或选择会话。输入框底部“自动引用”开关开启时，默认引用 IDEA 当前标签页文件；选择代码时自动
   显示并随任务发送 `@项目相对路径#L起始行-L结束行`，取消选区后恢复整个文件引用。
   切换标签页自动更新引用；关闭开关只关闭自动引用，不删除手动插入的引用。
   在项目文件树（支持多选文件或目录）、编辑器标签页、代码编辑区右键“发送到 UData Harness 对话框”，
   可将文本引用插入输入框记住的光标位置；输入框有选中文本时替换该文本。同一文件的多个代码段可分次插入，
   既有引用不会被覆盖。右击其他标签页时引用右击的文件，不使用当前活动标签页。
   文件引用使用 `@路径`，选区引用使用 `@路径#L起始行-L结束行`，便于在一句指令中组合多处引用。
   也可以点击侧栏的
   “添加选区”或“添加当前文件”。附件发送前可预览、移除；每次最多 8 个，总内容上限 200000 字符。
   输入任务后发送，正文、思考、工具调用、模型选择、权限、审批与停止均复用网页实现。

5. 点击文件活动中的路径，在 IDEA 编辑器打开文件。任务结束后同步磁盘变化。
   如项目有未保存文件，发送前询问是否保存；运行期间的新编辑不会被插件覆盖。
   同步时若有未保存内容，保留编辑器内容，必要时打开磁盘与编辑器的原生 Diff；处理后点击“同步文件”。

6. 点击“网页工作台”，浏览器使用同一用户和工作区打开完整 Web 界面。MCP、Skill、Agent、Loop、Goal
   继续通过网页管理。两端每 5 秒查询会话状态；另一端任务完成后刷新历史，也可恢复待审批卡片。
   当前只在发起端显示实时 SSE，另一端显示执行状态和完成后的历史。

## 实现边界

- 全部后端通信采用 REST 和 HTTP SSE，没有 WebSocket；JS 桥接只连接插件内网页与 IDEA。
- 不会通过注册 IDEA 项目修改用户的 Web 默认工作区；两端请求带 `X-Workspace-Id` 独立选择工作区。
- Agent 仍直接修改磁盘。当前 Diff 用于未保存内容冲突查看，不提供修改前逐项批准、补丁应用或原生撤销保证。
- 远程后端、自动启动服务、诊断/引用检索、修改补丁预览属于后续扩展。
- `X-User-Id` 沿用现有隔离机制，不是认证；插件桥接仅开放固定方法，并校验文件位于当前项目真实路径内。
- IDEA 项目关闭会释放浏览器和桥接。活跃 SSE 连接关闭沿用后端的订阅取消行为；服务进程继续运行。

## Windows 构建排障

若 JDK 报 `Unable to establish loopback connection` 且堆栈涉及 Unix-domain sockets，可为本次构建指定
已存在的短临时目录，例如 `$env:JAVA_TOOL_OPTIONS='-Djdk.net.unixdomain.tmpdir=D:/tmp'`。
若 Microsoft JDK 构建插桩报 `Packages does not exist`，使用另一个完整的 JDK 21 运行 Gradle。

本次在 Oracle JDK 21 下完成编译、插件 ZIP 打包和结构校验；实际 IDEA 内的完整模型执行仍需配置模型后验收。

## 0.1.1 桥接修复

修复页面能打开但提示“IDEA 桥接尚未就绪”的问题：`JBCefBrowser` 已向底层 `CefClient`
注册加载和请求回调，底层接口的单回调槽会忽略后续注册。插件改为通过 `JBCefClient`
的多回调分发器注册，并保留对当前页面的导航限制。

桥接注入后主动向 IDEA 握手，顶部显示“IDEA 已连接 · 用户标识”；15 秒未完成握手时提示重新连接。
桥接脚本支持重复注入、独立请求回复、失败处理和超时清理，运行 `node --test test/bridge.test.cjs` 验证。
从 0.1.0 升级只需要安装新版插件 ZIP 并重启 IDEA，无需重新构建或重启 Solon 服务。

## 0.1.2 自动引用和右键引用

新增 IDEA 当前文件、选区引用同步和文件树/标签页右键引用。引用采用文本路径和行范围，沿用网页的
输入框展示与发送方式；既有代码快照附件继续保留。自动引用在发送时读取最新选区，手动引用同一文件时
保留用户指定的范围。关闭所有编辑器或切换到项目外文件时，清除自动引用。

本版本同时修改了后端提供的网页资源，升级时需要安装插件 0.1.2，并重新构建前端、打包和重启后端。
前端引用测试：`node --test frontend/test/ideaReferences.test.js`（仓库根目录执行）。

## 0.1.3 引用接收修复

移除 IDEA 样式中隐藏引用开关的规则，输入框下方明确显示“自动引用”。右键文本文件时插入
`\n@项目相对路径#L起始行-L结束行\n`；未选择代码时使用整份文本文件的行范围。
目录、二进制文件及超过 2 MB 的文件仍使用路径引用。

插件保留引用队列，页面初始化后读取并确认；确认失败会重试，不重复插入。没有当前会话时自动
创建一个会话并展示对话框。5 秒未接收时，插件顶部提示更新后端页面并重新连接。
升级时安装插件 0.1.3，并使用最新网页资源重新打包和重启后端。

## 0.1.4 分步、多处引用

右键菜单统一为文本引用，不再将“发送到 UData Harness”作为按文件去重的代码快照附件。
引用插入输入框失焦前记住的光标或选区位置，插入后将光标放在引用后，支持继续输入、再次右键引用。
适配多处引用的行内组合，新增引用不强制前后换行；旧版插件发送的换行格式仍原样保留。
例如可分次组成 `请你根据 @docs/spec.md 改造 @src/Main.java#L1-L25 的代码`。
代码快照附件仍可通过“添加选区”和“添加当前文件”按钮使用。

## 0.1.5 输入框引用标签

IDEA 对话输入框使用可编辑文本与独立的引用标签，右键发送的文件路径或代码范围各自显示为一块标签。
标签保留完整引用，可与普通指令交错排列，多处引用不会合并成同一附件。输入框复制及发送时将标签还原为
`@路径` 或 `@路径#L起始行-L结束行`，模型接口保持原有文本格式。普通网页继续使用原有文本输入框。
此版本需要更新后端网页资源并重启后端；已经安装 0.1.4 的插件也兼容标签显示，无需更换插件。

## 0.1.6 引用快捷键

“发送到 UData Harness 对话框”默认绑定 `Alt+K`。编辑器内选中代码后按快捷键，会插入带行号范围的引用；未选中代码时插入文件路径引用。项目文件树中也可选择一个或多个文件/目录后按快捷键。右键菜单与快捷键使用同一个动作，沿用多处引用标签和输入框光标位置。

如果当前 Keymap 的 `Alt+K` 已分配给其他操作，在 IDEA 的 Settings → Keymap 中搜索“发送到 UData Harness 对话框”调整绑定或移除冲突。此版本需要安装新版插件 ZIP 并按 IDEA 提示重启；无需更新后端。
